# Demo D3: Hinglish end to end on the owner's Mac

What you can see:
- `bhavna` in a terminal, hold Right Option, speak Hinglish or English, release: the text lands at the
  cursor. A "tink" on start, a "pop" when the text is in (3x volume, owner's pick after trying 3, 5, 10).
- Owner's first session (2026-10-07, 15:56 to 16:17): 11 dictations, 2.2 s to 24 s of speech,
  6 to 95 words each. ASR 0.58 s (2.2 s clip) to 5.1 s (24 s clip). About 0.2 s per spoken second.
- The owner's feedback message about the product was itself dictated through the product.

How to run it: `tools/install-shortcut.sh` once, then `bhavna`.

What was learned:
- Short dictation is under a second on an 8 GB M1 with Apex alone (lean profile). Long dictation
  scales linearly; a 95-word message takes 5 s. Streaming or chunking is the lever if that hurts.
- Accuracy: small spelling slips ("transparai"); the owner calls it fine for v1. The dictionary
  phase is the planned fix, not a bigger model.
- Bug #54: Terminal said "ok" to the Accessibility insert and inserted nothing. Fixed with a
  settable check; verified by the owner in Claude Code. Rule D12 (log the bug first) came from it.
- Not a bug #55: two dictation tools on the same modifier key collide. Run one.
