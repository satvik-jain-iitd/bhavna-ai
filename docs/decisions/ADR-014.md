# ADR-014: The dictionary is an explicit heard-to-correct list, applied in one pass before insert.

Status: accepted, 2026-10-09. Refines ADR-011.

Context: 166 logged dictations show the misheard words are names of people, brands and tools, heard the same few ways each time. ADR-011 planned a fuzzy `difflib` match against a word list.
Decision: `dictionary.tsv` maps each heard form to the correct form (heard, correct, times seen, mode). Only `auto` rows are swapped; `ask` rows are real words too and wait for the owner. Whole words, any case and spacing, one pass, longest phrase first. Read on every dictation. The raw model text stays in the log as `raw_text`.
Trade-off: a new mishearing is not fixed until it is in the list. Fuzzy matching would catch more but swap look-alike real words.
Consequence: no false swaps from similarity; the learn step (next story) adds rows from the owner's corrections. The file stays local and out of git: it holds personal and client names.
