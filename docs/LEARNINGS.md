# Learnings

Append-only (ShipQuick rule 26). Never edit or delete a row. Read with `docs/process-trace.md`.

| # | Date | Lesson |
|---|---|---|
| 1 | 2026-10-27 | Situation: bhavna, reviewer session bhavna-qa opened PR #126 (dev to main) itself with the dev account's token, while a developer session existed. Root cause: the reviewer took a developer action because it was faster; no rule line said who opens the dev to main PR. Fix: #126 closed by the owner's merge; this row; bhavna CLAUDE.md rule 4 gets the line "bhavna-dev opens every PR, dev to main included; bhavna-qa only reviews and merges". Applies when: a project has separate developer and reviewer sessions and a PR must be opened. Does not apply to: a project with one session, or the first PRs before a developer session exists (then say so in the PR body). |
| 2 | 2026-10-27 | Situation: bhavna, PR #125 titled "docs: trace rows 90 to 92 (#122)" merged into dev; the ShipQuick script close_linked_issues closed issue #122 from the title, and bhavna-qa reopened it. Root cause: an issue number in brackets in a PR title counts as a closing link, and I wanted the issue to stay open. Fix: bhavna-qa retitled the PR; going forward "re #n" goes in the body, never the title, when the issue must stay open. Applies when: a PR must not close the issue it touches and the repo runs close_linked_issues. Does not apply to: a PR that should close its issue (then use "Closes #n" in the body as usual). |
| 3 | 2026-10-27 | Situation: bhavna, `gh workflow run roadmap-call.yml --ref dev` gave "HTTP 404: workflow roadmap-call.yml not found on the default branch"; the file was on dev only, main had only ci.yml. Root cause: GitHub reads workflow_dispatch, issues and workflow_run triggers from the default branch (main), not from the branch you pass. Fix: owner merged dev to main (#126); dispatch on main then ran green. Applies when: a workflow with those triggers is new and the default branch does not have it yet. Does not apply to: pull_request or push triggers, which run from the pushed branch. |
