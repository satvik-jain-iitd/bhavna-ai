# Passage 005: Terminal bina mouse ke

Read exactly as written. About 60 seconds. Commands are spoken as words ("control A").

Terminal ko bina mouse ke chalana ek baar seekh lo, phir haath keyboard se hatta hi nahi. Pehle, Terminal kholne ke liye command space dabao, Terminal likho, enter. Naya tab command T, tab band command W, aur tabs ke beech command shift bracket. Ab line ke andar. Control A se cursor line ke shuru mein, control E se aakhir mein. Control U poori line mita deta hai, control K cursor ke aage ka hissa. Option left aur option right se ek ek shabd kood sakte ho. Sabse kaam ki cheez hai tab, jo file aur folder ke naam khud poora kar deta hai. Purana command chahiye to up arrow, aur history mein dhoondhna ho to control R dabao aur kuch akshar likho. Koi command atak jaaye to control C, screen saaf karni ho to control L, aur bahar nikalna ho to control D. Folder badalne ke liye cd, list ke liye ls, aur yeh jaanne ke liye ki tum kahan ho, pwd. Bas yeh pandrah shortcuts, aur mouse ki zaroorat khatam.
