# Bhavna.ai

Local Hinglish dictation. One key. Instant. No bloat.

Hold one key, speak Hindi, English or both mixed, release. Your exact words land at the cursor.
Two models stay in memory, a tiny router picks one per clip, nothing leaves the machine.
